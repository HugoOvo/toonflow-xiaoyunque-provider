小云雀 → Toonflow 使用说明
================================

文件：xyq.ts （Toonflow 自定义供应商插件，不要改后缀）
当前版本：2.5.0

------------------------------------------------
现在是什么状态（2026-10-16 更新到 2.5.0，已实测）
------------------------------------------------
2.5.0 这次加了两个小东西：
  - 粘贴 API Key 时多带「Bearer 」前缀会自动去掉（以前会认证失败）。
  - 参考图超过 4096 像素先在本地压小再上传，超大图上传和生成都更快。
    小云雀本身不限制参考图尺寸，所以这只是提速，不影响能不能用。
已经用你的账号真跑通了，视频和图片都能正常回到 Toonflow：
  1) 橘猫视频（Seedance 2.0 Mini 体验版，4 秒 720P）
     → 165 秒出片，扣 16 积分。
  2) 草帽猫图片（Seedream 5.0 Flash，16:9，1.5K）
     → 60 秒出图，1 张，扣 3 积分。

之前你遇到的「视频在小云雀官网能看到、但 Toonflow 里一直转圈然后报无法计算价格」
是一个 bug：插件去查任务进度时多带了一个参数，小云雀就只回一段纯文字、
不回结构化结果，插件永远看不到「已完成」这一步。已经改掉，现在正常了。

顺手还修了两个会白花积分的坑：
  - 小云雀出图默认一次出 4 张（扣 4 份积分），但 Toonflow 的图片节点一次只要
    一张，多出的 3 张原来会被丢掉。现在改成：没特别指定时只出 1 张；如果一次出了
    多张，也全部交给 Toonflow，不再浪费。
  - 顺便加了价格显示（只写「按积分计费」，不编具体单价，下面有说明）。

注意：本次已经把插件装进 Toonflow，并且把你这台机器上的 API Key 直接填好了。
如果 Toonflow 里还留着旧的视频节点，把节点上的模型重选一次再点生成。

------------------------------------------------
第一步：拿到小云雀的 Access Key（已帮你填过，换电脑才需要重做）
------------------------------------------------
1. 浏览器打开 https://xyq.jianying.com 并登录
2. 找到【CLI/API】入口，切到【API】标签
3. 新建一个 Access Key，复制下来（一串字符，只显示一次，丢了就重建）

------------------------------------------------
第二步：装进 Toonflow
------------------------------------------------
1. 打开 Toonflow → 设置 → 媒体模型（视频模型）
2. 点【添加自定义供应商】→ 选【文件导入】
3. 选中本文件夹里的 xyq.ts → 添加

添加后表单里：
  API Key   → 粘贴上一步复制的 Access Key   ← 只需要填这个
  请求地址  → 保持默认 https://xyq.jianying.com

粘贴 Key 时如果多带了「Bearer 」前缀也没关系，插件会自动去掉，不会报认证失败。

------------------------------------------------
第三步：用
------------------------------------------------
【视频】新建视频节点，模型下拉里选「小云雀 Pippit」下面的模型。
这 7 个是你这个账号真正有权限的（其他模型提交上去会被服务端拒绝）：
  1. Seedance 2.5              4~30 秒，480P/720P/1080P，参考图最多 30 张
  2. Seedance 2.0 Vision       4~15 秒，480P/720P/1080P/4K，参考图 9 张
  3. Seedance 2.0 Fast Vision  4~15 秒，480P/720P，参考图 9 张
  4. Seedance 2.0 Mini         4~15 秒，720P，参考图 9 张
  5. Seedance 2.0 Mini 体验版   4~15 秒，720P，参考图 9 张（最便宜，先拿它试）
  6. Wan 3.0                   4~30 秒，480P/720P/1080P，参考图 10 张
  7. HappyHorse 1.1            3~15 秒，720P/1080P，只能传参考图，不支持首尾帧
写提示词，需要的话传参考图 / 参考视频 / 音频 / 首尾帧，然后生成。

【图片】新建图片节点，模型下拉里选同一家的图片模型。
这 9 个是你账号有权限的：
  Seedream 5.0 Pro、Seedream 5.0 Flash、Midjourney 美学 8.2、
  智能图片 V2.5 Pro、智能图片 V2.5 Fast、智能图片 V2、
  旗舰生图 V2-Pro、旗舰生图 V2-Flash、Anycook 影视版
可以文生图，也可以传参考图改图。

生成的视频 / 图片用的都是你自己小云雀账号里的积分，按积分扣费。
想看还剩多少积分：供应商那一栏点余额查询（2026-10-16 查是 1289 积分，实时值）。

------------------------------------------------
关于价格显示
------------------------------------------------
节点右上角那个价格只显示「按积分计费（每秒 / 每张）」，不会显示具体多少钱。
原因：小云雀没有对外的估价接口，我也查不到官方公开单价。
所以这里宁可不显示，也不编一个假数字骗你。
真实扣费看你小云雀账号里的积分流水，或者生成前后各查一次余额自己减。

------------------------------------------------
关于参考图大小
------------------------------------------------
小云雀本身没写死参考图的尺寸上限，但特别大的图（长边超过 4096 像素）上传慢、
后面生成也慢。所以插件会先在本地把这类超大图等比压到 4096 像素以内再上传，
小图原样不动，不会放大、也不会改变比例。压缩失败的特殊格式（比如 svg）
会原样上传，不影响你出片。

------------------------------------------------
关于音频（重点）
------------------------------------------------
小云雀没有「文字转语音」这种独立的音频生成接口，所以这里也没有音频模型。
音频只能当作视频的参考素材传进去（声音当参考，或者让视频带上配乐），
支持 mp3 / wav 两种格式。要纯做配音，得用别的工具。

------------------------------------------------
注意
------------------------------------------------
- 上面列的模型是按你账号的模型接口实测查出来的，不是猜的。
  如果哪天报「没有权限」或「模型不存在」，说明账号权限变了，告诉我重新查。
- Seedance 2.5 Draft（先出 480P 样片再渲染成片）是两步流程，插件里一次提交做不了，
  要用它请直接去小云雀网页版。
- 单个素材请小于 500MB。
- 图片支持 jpg/jpeg/png/gif/bmp/webp/svg，视频支持 mp4/avi/mov/wmv/flv/webm/mkv/m4v，
  音频支持 mp3/wav。
- 生成中途别关软件，视频最长等 30 分钟，图片最长等 15 分钟。
- 老外那个有问题的 xiaoYunque.ts 已经从 Toonflow 里移走了（备份在「_坏文件备份」文件夹），
  里面画布上那个空视频节点也已经改指向「小云雀 Pippit」，不用再手动改。
- 本插件只是把 Toonflow 的请求转发给小云雀官方接口，不额外收费、
  不经过第三方，积分消耗以你小云雀账号里显示为准。

------------------------------------------------
遇到问题怎么办
------------------------------------------------
把 Toonflow 里弹出来的报错文字整段发我，我照着改。
小云雀偶尔会调整接口，报「模型不存在」这类错通常就是这个原因。
